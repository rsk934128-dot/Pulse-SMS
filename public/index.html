উন্নত সুবিধাসমূহ

সব মেসেজিং প্রয়োজন এক জায়গায়

অ্যান্ড্রয়েড ফোনের সম্পূর্ণ টেলিফোনি সাপোর্ট এবং ক্লাউড এআই-এর সমন্বয়ে নির্মিত।

রিয়েল-টাইম Heads-Up নোটিফিকেশন

এসএমএস আসার সাথে সাথেই ফোনের স্ক্রিনের ওপর হাই-প্রায়োরিটি ব্যানার ভেসে ওঠে। নোটিফিকেশন থেকেই এক ক্লিকে ওটিপি কপি বা রিপ্লাই দেওয়া যায়।

স্মার্ট ওটিপি ও লেনদেন ফোল্ডার

ব্যক্তিগত বার্তা, ব্যাংক ও বিকাশ ট্রানজাকশন, এবং ওটিপি স্বয়ংক্রিয়ভাবে আলাদা ফোল্ডারে ফিল্টার হয়ে যায়। ওটিপি আসলে কোড কপি বাটন তৈরি হয়।

Google Gemini 2.5 Flash AI

চ্যাট কনটেক্সট বুঝে বাংলা ও ইংরেজিতে স্মার্ট রিপ্লাই দেয়, সন্দেহভাজন স্প্যাম বা ফিশিং লিঙ্ক স্ক্যান করে সতর্ক করে এবং লম্বা থ্রেড সারসংক্ষেপ করে দেয়।

ডুয়াল সিম (Dual SIM) সাপোর্ট

সিম ১ বা সিম ২ নির্বাচন করে সরাসরি ক্যারিয়ার এসএমএস পাঠানোর পূর্ণ স্বাধীনতা। রয়েছে রিয়েল ক্যারেক্টার কাউন্টার (১৬০ অক্ষর লিমিট)।

কম্পিউটার ও ব্রাউজার সিঙ্ক

ফোন পকেটে রেখেই ডেস্কটপ থেকে মেসেজ পড়ুন এবং টাইপ করুন। Firebase Firestore দিয়ে সকল মেসেজ সুরক্ষিত ক্লাউডে ব্যাকআপ থাকে।

Google Sign-In ও নিরাপত্তা

Jetpack Credential Manager এবং Firebase Zero-Trust Security Rules দ্বারা সুরক্ষিত। শুধুমাত্র আপনার অনুমোদিত গুগল অ্যাকাউন্টেই ডেটা সুরক্ষিত থাকে।

Vercel Deployment Guide

ভার্সেল (Vercel)-এ এই ওয়েবসাইটটি ডিপ্লয় করার নিয়ম

কোনো সার্ভার কনফিগারেশন ছাড়াই মাত্র ৩টি সহজ ধাপে সম্পূর্ণ ফ্রি-তে লাইভ করুন।

১

গিটহাবে রিপোজিটরি পুশ করুন

আমাদের তৈরি করা vercel.json এবং index.html ফাইলসহ প্রজেক্টটি আপনার GitHub অ্যাকাউন্টে পুশ করুন: 

git add .
git commit -m "feat: add vercel web companion"
git push origin main
২

Vercel-এ প্রজেক্ট ইমপোর্ট করুন

vercel.com-এ লগইন করে "Add New..." -> "Project" সিলেক্ট করুন এবং আপনার Pulse-SMS রিপোজিটরিটি Import বাটনে ক্লিক করুন।

💡 Framework Preset পরিবর্তন করার প্রয়োজন নেই (Other / Static)।
৩

"Deploy" বাটনে ক্লিক করুন!

নীল রঙের "Deploy" বাটনে চাপ দিন। Vercel মাত্র ১০ সেকেন্ডের মধ্যে আপনার জন্য একটি লাইভ ডোমেইন তৈরি করে দেবে (যেমন: pulse-sms.vercel.app)।

✅ এর পর থেকে গিটহাবে পুশ করলেই স্বয়ংক্রিয়ভাবে সাইট আপডেট হবে।

Pulse SMS অ্যান্ড্রয়েড অ্যাপ ইনস্টল করুন
